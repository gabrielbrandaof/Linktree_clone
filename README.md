## 📌 Sobre o Projeto

Este projeto consiste em uma página estilo **Linktree** desenvolvida de forma personalizada para uma **corretora imobiliária**. A aplicação centraliza em um único link os principais canais de atendimento, catálogo de imóveis, redes sociais e formulários de contato.

O foco principal do desenvolvimento foi a criação de uma interface limpa, intuitiva e totalmente otimizada para dispositivos móveis (mobile-first), garantindo uma experiência fluida para os clientes que acessam via Instagram, WhatsApp ou outras redes.

🔗 **Acesse o projeto online:** [gabrielbrandaof.github.io/Linktree_clone](https://gabrielbrandaof.github.io/Linktree_clone)

---

## 🚀 Funcionalidades

- **Design Responsive & Mobile-First:** Adaptado para smartphones, tablets e desktops.
- **Centralização de Links:** Atalhos para WhatsApp, catálogo de imóveis, site oficial e redes sociais.
- **Interatividade:** Animações e efeitos *hover* sutis para melhorar a navegação do usuário.
- **Carregamento Rápido:** Estrutura leve desenvolvida em código nativo (Vanilla HTML/CSS/JS).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout responsivo (Flexbox/Grid) e animações.
- **JavaScript (ES6+):** Manipulação do DOM e comportamentos dinâmicos.
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.
